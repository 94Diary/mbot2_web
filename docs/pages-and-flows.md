## แผนผังเว็บ

```
หน้าเว็บ (layout: header + footer)
├─ หน้าแรก (home)
├─ บทเรียน (lessons) → อ่านบทเรียน (lesson/:id)
├─ รู้จักหุ่น (robot)
├─ ค้นหา (search)
├─ เกี่ยวกับ (about) · ติดต่อ (contact)
├─ นโยบายความเป็นส่วนตัว (privacy) · ข้อตกลง (terms)
└─ 404 · 500 · ปิดปรับปรุง

บัญชี (layout: กล่องกลางจอ)
├─ เข้าสู่ระบบ (login) · สมัครสมาชิก (register)
├─ ลืมรหัสผ่าน (forgot) · ตั้งรหัสผ่านใหม่ (reset/:token)
└─ โปรไฟล์ (profile) — แท็บ: ข้อมูล / ความปลอดภัย / อุปกรณ์ที่เข้าสู่ระบบ / เครื่องที่จับคู่ / การแจ้งเตือน / ข้อมูลและความเป็นส่วนตัว

ตัวเชื่อมเครื่อง (setup) — ติดตั้ง อนุญาต จับคู่ ตรวจเครื่อง

คอนโซลหุ่น (layout: header + แถบเมนูล่างล็อก)
├─ เชื่อมหุ่น (connect) — แท็บ ซิม / หุ่นจริง
├─ วางหุ่น (place) — หุ่นจริงเท่านั้น
├─ ควบคุม (control)
├─ หุ่นของทีม (bot/:i)
├─ ประวัติของฉัน (history)
└─ รายละเอียดภารกิจ (mission/:id) — แท็บ สรุป / แผนที่ / Log

หลังบ้าน (layout: sidebar + topbar)
├─ ภาพรวม: Dashboard เว็บ (a_dash) · สถานะระบบ (a_system)
├─ เนื้อหา: บทเรียน (a_lessons, a_lesson_edit) · ประกาศ (a_ann)
├─ ผู้ใช้และข้อมูล: ผู้ใช้ (a_users) · บทบาทและสิทธิ์ (a_roles) · ภารกิจและข้อมูล (a_missions)
└─ ระบบ: ตัวเชื่อมเครื่อง (a_agent) · ตั้งค่าเว็บ (a_settings) · ความปลอดภัย (a_security) · สำรองข้อมูล (a_backup) · Audit log (a_audit)
```

## สถานะร่วมที่ทุกหน้าต้องรองรับ

| สถานะ | แสดง |
|---|---|
| กำลังโหลด | Skeleton ตามรูปทรงเนื้อหา (ไม่ใช้ spinner กลางจอ) |
| ไม่มีข้อมูล | EmptyState: ไอคอน + หัวข้อ + บอกขั้นต่อไป + ปุ่ม |
| ผิดพลาด | ข้อความภาษาคน บอกวิธีแก้ ใต้ช่องที่ผิด หรือ Notice สีแดง |
| ไม่มีสิทธิ์ | Gate 403 พร้อมปุ่มไปหน้าที่เข้าได้ |
| ประกาศ | Banner บนสุด ปิดได้ |
| โหมดปิดปรับปรุง | คนทั่วไปเห็นหน้าปิดปรับปรุง ผู้ดูแลเห็น banner แดง |
| คุกกี้ | CookieBanner ล่างจอจนกว่าจะเลือก |

## หน้าเว็บสาธารณะ

**หน้าแรก**
- hero: ข้อความ “รู้จัก mBot2 หุ่นที่สำรวจเป็นทีม” + ปุ่ม “เข้า Dashboard” และ “เริ่มบทเรียน” + รูป/โมเดลหุ่นด้านขวา
- 3 ส่วนตอบคำถาม: mBot2 คืออะไร · เว็บนี้ทำอะไร · เริ่มใช้งานยังไง (เตรียมเครื่อง → ติดตั้งตัวเชื่อม → กดรันซิม → บันทึกผล)
- CTA สุดท้าย: ล็อกอินแล้ว = เปิดคอนโซล · ยังไม่ล็อกอิน = เข้าสู่ระบบ / สมัคร

**บทเรียน** — การ์ดเรียงตามลำดับ 13 บท · ความคืบหน้า (สมาชิก) · ร่างเห็นเฉพาะผู้ดูแล
บทเรียนปัจจุบัน:
1. รู้จักโปรเจกต์
2. ติดตั้ง WSL และ Ubuntu
3. ติดตั้ง ROS 2 และ Gazebo
4. ดึงโค้ดทีมและ build ครั้งแรก
5. **ติดตั้งตัวเชื่อมเครื่อง**
6. **รันซิมครั้งแรกจากเว็บ**
7. Topic, node และ namespace
8. อ่านเซนเซอร์ของหุ่น
9. หุ่นตัดสินใจที่ทางแยกยังไง
10. แผนที่ร่วมของทีม
11. หลบกันเมื่อวิ่งสวนทาง (ร่าง)
12. ย้ายจากซิมไปหุ่นจริง (ร่าง)
13. แก้ปัญหาที่เจอบ่อย

**รู้จักหุ่น** — โมเดล 3D กดชิ้นส่วนแล้วลอยออก (ต้นแบบ `../site/robot.html` — caster ล้อหน้าลอยลงด้านล่าง) + รายละเอียดชิ้นส่วน
**ค้นหา** — ค้นบทเรียน หน้า และปัญหาที่เจอบ่อย · มีคำแนะนำ · ไม่พบ = ปุ่มดูบทเรียนทั้งหมด / ถามทีม
**ติดต่อ** — ฟอร์ม (ชื่อ อีเมล หัวข้อ ข้อความ CAPTCHA) + ช่องทางติดต่อ

## บัญชี

| หน้า | สถานะที่ต้องมี |
|---|---|
| เข้าสู่ระบบ | ผิดรูปแบบอีเมล · รหัสผิด (นับครั้ง) · CAPTCHA หลังผิด 3 ครั้ง · ล็อก 15 นาทีหลังผิด 5 ครั้ง · บัญชีถูกระงับ (เหตุผล วันหมด ปุ่มอุทธรณ์) · แสดง/ซ่อนรหัส · จำฉันไว้ 30 วัน |
| สมัคร | โหมดเปิด / ต้องมีรหัสเชิญ / ปิดรับ · แถบความแข็งแรงรหัสผ่าน · ยอมรับข้อตกลง · CAPTCHA · หน้า “เช็กอีเมล” |
| ลืมรหัส | ข้อความเดียวกันเสมอไม่ว่ามีบัญชีหรือไม่ |
| ตั้งรหัสใหม่ | ลิงก์หมดอายุ · รหัสสองช่องไม่ตรง · สำเร็จแล้วออกจากระบบทุกเครื่อง |
| โปรไฟล์ | 6 แท็บ (ดูแผนผัง) · ลบบัญชีอยู่ใน danger zone ต้องใส่รหัสผ่าน |

## ตัวเชื่อมเครื่อง (setup)

4 ขั้น แสดงขั้นปัจจุบันด้วยกรอบส้ม ขั้นที่ผ่านแล้วเป็นติ๊กเขียว:
1. **เครื่องพร้อมรัน ROS** — รายการตรวจ (ผลจริงหลังติดตั้งตัวเชื่อม)
2. **ติดตั้งตัวเชื่อม** — คำสั่ง + ปุ่มคัดลอก + “คำสั่งนี้ทำอะไรกับเครื่องบ้าง”
3. **อนุญาตเบราว์เซอร์** — ภาพตัวอย่างหน้าต่าง Chrome · ถ้าถูกบล็อก แสดงวิธีเปิดสิทธิ์
4. **จับคู่** — รหัส 6 หลัก + ชื่อเครื่อง

สถานะตัวเชื่อม: `none` ยังไม่ติดตั้ง · `off` ไม่ได้เปิด · `blocked` เบราว์เซอร์บล็อก · `unpaired` ยังไม่จับคู่ · `outdated` เวอร์ชันเก่า (ยังใช้ได้) · `ok`
คอนโซลทุกหน้ามี **AgentStatusChip** มุมขวาบน กดแล้วมาหน้านี้

## คอนโซลหุ่น

แถบเมนูล่าง (ล็อกติดขอบล่างเสมอ): ควบคุม · เชื่อมหุ่น · ประวัติ · หุ่นของทีม · **หยุดทุกตัว** (สีแดง ขวาสุด)
ทุกหน้าในคอนโซลเช็กลำดับนี้ก่อน: บัญชีถูกระงับ? → ตัวเชื่อม ok? → ตรวจเครื่องผ่าน? → แสดงหน้า

**เชื่อมหุ่น — ซิม**
- ฟอร์ม: จำนวนหุ่น (2/3) · โลกในซิม (+ เพิ่มโลกใหม่ .sdf) · Build ใหม่ก่อนรัน · ซ่อน Gazebo · แผนที่อ้างอิง (ไม่บังคับ) · ตั้งค่าหุ่นขั้นสูง (เวลารอที่ทางแยก, ความเร็ว) · ดูคำสั่งที่จะรัน
- ปุ่ม “รันซิม N ตัว”
- แผงความคืบหน้า 4 ขั้น + กล่อง “ข้อความจาก Terminal”
- สำเร็จ → ไปหน้าควบคุมเอง + toast “ซิมพร้อมแล้ว หุ่นวิ่งอยู่ N ตัว”
- ล้มเหลว → Notice แดง (ไฟล์ บรรทัด) + ปุ่ม “วิธีแก้” + “แก้แล้ว รันอีกครั้ง”
- ผู้เยี่ยมชม/ยังไม่ยืนยันอีเมล → Notice ฟ้า “รันได้ แต่บันทึกขึ้นเว็บไม่ได้”

**เชื่อมหุ่น — หุ่นจริง** — รายการหุ่นที่เจอ (ชื่อ ns IP แบต ปุ่มแก้ชื่อ/สี) · ค้นหาอีกครั้ง · ไม่เจอ = EmptyState + วิธีแก้
**วางหุ่น** — แผนที่จุดเริ่ม + Notice เตือนก่อนเริ่ม (ไม่มีช่องติ๊ก) + เตือนแบตต่ำ + “วางแล้ว ไปหน้าควบคุม”

**ควบคุม**
- หัว: ภารกิจ #N + สถานะ (พร้อมเริ่ม / กำลังวิ่ง mm:ss / จบแล้ว) + แหล่ง/โลก/ผู้เริ่ม + ปุ่ม (เริ่มสำรวจ / จบภารกิจ / บันทึก + ทิ้งผล)
- แถวการ์ดเลือกหุ่น: ทุกตัว + การ์ดหุ่นแต่ละตัว (เลือกแล้วขอบสีของหุ่น)
- แผนที่ (ตามหุ่นที่เลือก) + ตัวเลือกการแสดง 3 แบบ + คำอธิบายสัญลักษณ์
- Log สด (ตามหุ่นที่เลือก) + จำนวนรายการ
- สถานะไม่มีภารกิจ → Gate ไปรันซิม/ค้นหาหุ่น
- ROS หลุด → banner แดง “ข้อมูลหยุดที่ hh:mm:ss · กำลังลองใหม่”
- ตัวเชื่อมหลุดระหว่างวิ่ง → banner แดง “ปุ่มหยุดใช้ไม่ได้จนกว่าจะเชื่อมใหม่”

**ประวัติของฉัน** — **รายการยาวลงมาอย่างเดียว** ไม่มีส่วนสรุปด้านบน
- แถบเครื่องมือ: ค้นหา (#รอบ / ชื่อแผนที่) · กรองผล (ทั้งหมด/ครบ/บางตัว/หยุด) · กรองโลก · เรียง (ใหม่/เก่า)
- Pager บนและล่าง (10/20/30/50 ต่อหน้า)
- รายการจัดกลุ่มตามวัน (หัววันค้างตอนเลื่อน) แต่ละแถว = HistoryRow

**รายละเอียดภารกิจ** — แท็บ สรุป (ตัวเลข + หุ่นแต่ละตัว + สภาพแวดล้อม) / แผนที่ (+ ตั้งชื่อ/ดาวน์โหลด) / Log (+ CSV) · ใช้ตัวเลือกหุ่นตัวเดียวคุมแผนที่และ log

## User flows หลัก

**A. ผู้ใช้ใหม่ → รันซิมครั้งแรก**
หน้าแรก → เปิดคอนโซล → (ตัวเชื่อม none) หน้า setup → คัดลอกคำสั่ง → ติดตั้งใน Ubuntu → ตรวจหาตัวเชื่อม → Chrome ขอสิทธิ์ → อนุญาต → ใส่รหัส 6 หลัก → “ไปรันซิม” → เลือกจำนวน/โลก → รันซิม → หน้าควบคุมเอง → จบภารกิจ → บันทึก (ไม่ได้ล็อกอิน = เข้าสู่ระบบหรือดาวน์โหลด .zip)

**B. สมาชิกประจำ** — เปิดคอนโซล → (มีภารกิจค้าง) ควบคุม · (ไม่มี) เชื่อมหุ่น → รันซิม → ควบคุม → จบ → บันทึก (ตั้งชื่อแผนที่ได้) → ไปหน้ารายละเอียดภารกิจ

**C. แก้โค้ดแล้วรันใหม่** — แก้ใน VS Code → เว็บ: รันซิม (Build ใหม่ก่อนรันเปิดอยู่) → ถ้า build ล้ม อ่านไฟล์/บรรทัด → แก้ → “แก้แล้ว รันอีกครั้ง”

**D. หุ่นจริง** — เชื่อมหุ่น › หุ่นจริง → ค้นหา → ต่อไป → อ่านคำเตือน → วางแล้ว → ควบคุม → เริ่มสำรวจ

**E. ผู้ดูแลระงับสมาชิก** — หลังบ้าน › ผู้ใช้ → ค้นหา → จัดการ → ระงับหรือแบน → เหตุผล/ระยะเวลา/ข้อความ/บันทึกภายใน → ระงับ → Audit log + อีเมลแจ้ง

**F. สมาชิกถูกระงับ** — ล็อกอิน → หน้า “บัญชีนี้ถูกระงับ” (เหตุผล ถึงวันไหน) → ขออุทธรณ์ → ฟอร์มติดต่อ

## Responsive

| ความกว้าง | การเปลี่ยน |
|---|---|
| > 1000px | เต็มรูปแบบ · หลังบ้านมี sidebar |
