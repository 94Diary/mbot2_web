## ระยะ

ใช้ช่วง 4 / 6 / 8 / 10 / 12 / 14 / 16 / 18 / 22 / 24 / 28 / 56
- การ์ด padding 20×22 · ช่องระหว่าง grid 16 · หน้า padding ซ้ายขวา 24 (≤700px = 16)
- ความกว้างเนื้อหาสูงสุด 1320 · เอกสาร/บทเรียน 820–900

## ขนาดเป้ากด

ปุ่มปกติ 44 · ปุ่มเล็ก 36 · ปุ่มไอคอน 40 · แท็บเมนูล่างมือถือ 56 · ไม่ต่ำกว่า 36 ทุกกรณี

## การเคลื่อนไหว

| ชื่อ | ค่า | ใช้กับ |
|---|---|---|
| fadeup | 0.3s `cubic-bezier(.16,1,.3,1)` ขึ้น 8px | เปิดหน้า, modal, drawer, toast |
| hover ปุ่ม | ยก -1px · กด +1px | |
| skeleton | ไล่เงา 1.2s วน | |
| led | กะพริบ 1.6s | จุดสถานะออนไลน์ |
| ping | วงกระเพื่อม 1.8s | ตำแหน่งหุ่นบนแผนที่ |
| spin | 0.9s | ↻ กำลังทำ |

- **ห้ามเล่นแอนิเมชันซ้ำทุกครั้งที่ state เปลี่ยน** (เช่น พิมพ์ในช่อง) เล่นเฉพาะตอนเปิดหน้า/เปิด modal ครั้งแรก
- เคารพ `prefers-reduced-motion`
