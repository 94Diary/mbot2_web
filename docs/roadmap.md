## ทดสอบก่อนเปิดสาธารณะ

- [ ] Chrome: ขอสิทธิ์ Local Network Access / อนุญาต / บล็อกแล้วเปิดใหม่
- [ ] Edge, Firefox, Safari: พฤติกรรมกับ localhost (แสดงข้อความถ้าไม่รองรับ)
- [ ] ตัวเชื่อมปฏิเสธ Origin อื่น · token ผิด · คำสั่งนอกตาราง · ชื่อโลกแปลก (`../`)
- [ ] API ตอบ 403 ทุก endpoint ที่ไม่มีสิทธิ์ (ทดสอบด้วยการยิงตรง ไม่ผ่าน UI)
- [ ] ถอดเจ้าของคนสุดท้ายไม่ได้
- [ ] ทุกหน้าใช้ได้ที่ 390 / 820 / 1440 px · ธีมสว่าง/มืด
- [ ] ทดสอบกู้คืนข้อมูลจริง 1 ครั้ง
