# สถาปัตยกรรมระบบ

## ภาพรวม

```
┌──────────────────────────── อินเทอร์เน็ต ────────────────────────────┐
│  เว็บ (HTTPS)  mbot2-maze.app                                        │
│  ├─ Frontend (SPA)                                                    │
│  └─ Backend API + DB + ที่เก็บไฟล์                                     │
│     เก็บ: บัญชี, บทเรียน, ประกาศ, ภารกิจที่บันทึก, Audit log, ตั้งค่า    │
└───────────────────────────────▲──────────────────────────────────────┘
                                │ HTTPS (REST)
┌───────────── เครื่องของผู้ใช้ (Windows) ─────────────────────────────┐
│  เบราว์เซอร์ (Chrome)                                                │
│        │ WebSocket  ws://localhost:8765   ← Chrome ขออนุญาตครั้งแรก   │
│        ▼                                                             │
│  WSL2 · Ubuntu 22.04                                                 │
│  ├─ ตัวเชื่อมเครื่อง (agent, Python)                                  │
│  │    ├─ รัน: colcon build / ros2 launch / rosbridge                  │
│  │    ├─ อ่าน/เพิ่มไฟล์ worlds/*.sdf                                   │
│  │    └─ รวม log + แผนที่ ตอนจบภารกิจ                                  │
│  ├─ ROS 2 Humble + ~/ros2_ws (โค้ดหุ่นของทีม)                         │
│  └─ Gazebo Fortress (หน้าต่างผ่าน WSLg)                               │
│                    │ Wi-Fi วงเดียวกัน                                  │
│                    ▼                                                 │
│               หุ่น mBot2 จริง                                         │
└──────────────────────────────────────────────────────────────────────┘
```

## ใครคุยกับใคร

| จาก → ถึง | ช่องทาง | ใช้ทำอะไร |
|---|---|---|
| เบราว์เซอร์ → Backend | HTTPS REST | ล็อกอิน, บทเรียน, บันทึก/อ่านภารกิจ, หลังบ้าน |
| เบราว์เซอร์ → ตัวเชื่อม | WebSocket `ws://localhost:8765` + token | สั่งรัน/หยุด, รับความคืบหน้า, รายชื่อโลก, ตรวจเครื่อง |
| เบราว์เซอร์ → rosbridge | WebSocket `ws://localhost:9090` (roslibjs) | ข้อมูลสดของหุ่น — **เฉพาะช่วงแรก** รุ่นหลังให้ตัวเชื่อมส่งต่อแทน |
| ตัวเชื่อม → ROS | subprocess + rclpy | รันคำสั่ง, อ่าน topic |
| Backend → ตัวเชื่อม | **ไม่มี** | เซิร์ฟเวอร์ไม่เคยคุยกับเครื่องผู้ใช้โดยตรง |

**ข้อสำคัญ:** ข้อมูลภารกิจไปถึงเซิร์ฟเวอร์ผ่านเบราว์เซอร์เท่านั้น ตัวเชื่อม → เบราว์เซอร์ → Backend เมื่อผู้ใช้กดบันทึก

## Deploy

- เว็บ + API: โฮสต์ที่รองรับ HTTPS (บังคับ เพราะ Local Network Access)
- โดเมนเดียว เช่น `mbot2-maze.app` · ตัวเชื่อมฝังโดเมนนี้ไว้เป็น allowed origin
- สำรองข้อมูล: DB + ไฟล์ภารกิจ ทุกวัน 03:00 ตามกฎ 3-2-1-1-0
- แยก environment: dev / staging / production · ตัวเชื่อมโหมด dev ยอมรับ `http://localhost:5173`

## จุดที่ต้องระวัง

1. **Local Network Access ของ Chrome:** ต้องจัดการสถานะ `prompt / granted / denied` ให้ครบ ถ้า denied ต้องบอกวิธีเปิด (ไอคอนแม่กุญแจ → การตั้งค่าเว็บไซต์ → เครือข่ายในพื้นที่)
2. **เบราว์เซอร์อื่น:** Safari/Firefox อาจทำงานต่างกัน ต้องทดสอบและแสดงข้อความถ้าไม่รองรับ
3. **เวอร์ชันโค้ดต่างกัน:** แต่ละคนอาจใช้โค้ดหุ่นคนละ commit ต้องเก็บ commit ไว้กับทุกภารกิจ
4. **ตัวเชื่อมหลุดกลางภารกิจ:** หุ่นในซิมยังวิ่ง แต่เว็บสั่งไม่ได้ ต้องเตือนแถบแดงว่าปุ่มหยุดใช้ไม่ได้
