# Component

รายการ component สำหรับสร้างเว็บจริง จัดกลุ่มตามชั้น: พื้นฐาน → ฟอร์ม → แสดงผล → ทับซ้อน → layout → เฉพาะโดเมน
ค่าสี ขนาด ความโค้ง อ้างอิง token ใน design-tokens.md (เช่น `--orange`, `radius.card`)
ชื่อ class ในวงเล็บคือชื่อที่ใช้ใน mockup ค้นดูโค้ดตัวอย่างได้

---

## 1. พื้นฐาน

### Button (`.btn`)
| prop | ค่า |
|---|---|
| `variant` | `default` (ขอบ โปร่ง) · `primary` (ส้ม) · `blue` · `chip` (พื้นขาว) · `danger` (แดงทึบ) · `ghostDanger` (ขอบ ตัวหนังสือแดง) |
| `size` | `sm` 36px · `md` 44px · `lg` 54px (ฟอนต์ Prompt) |
| `icon` | ไอคอนนำหน้า · `iconOnly` = ปุ่มกลม 40×40 ต้องมี `aria-label` |
| `loading` | แสดง ↻ หมุน + ข้อความ “กำลัง…” + disabled |
| `disabled` | opacity .45 · ไม่รับคลิก |

- ทรง pill ทุกปุ่ม · primary/blue/chip มีเงาด้านล่าง `inset 0 -3px 0` (ปุ่มพลาสติก)
- hover ยก -1px · active กด +1px
- ปุ่มไอคอนห้ามถูกบีบ (`flex: none`)

### Icon
- ชุดเส้น 24×24, stroke 2, ปลายมน (round cap/join)
- ชุดที่ใช้: search, theme, menu, x, arrow, back, bot, book, plug, ctrl, hist, set, stats, users, shield, key, db, doc, mega, log, heart, lock, user, mail, check, play, stop, wifi, dl, edit, trash, plus, eye, globe, flask, home, bell

### Pill / Badge (`.pill`)
`tone`: `go` เขียว · `warn` เหลือง · `red` แดง · `blue` ฟ้า · `orange` ส้ม · `gray` · `ink` (ทึบ)
ใช้กับ สถานะ ผลภารกิจ ระดับ log บทบาท · ขนาด 12.5px ตัวหนา

### Avatar (`.av`)
- `user`: วงกลม สีจากผู้ใช้ ตัวอักษรแรกของชื่อ
- `robot` (BotAvatar): สี่เหลี่ยมมุมโค้ง 32% สีหุ่น เลขลำดับ

### Dot / LED
จุดสี 8px · `pulse` กะพริบ = กำลังทำงานอยู่

### Skeleton (`.skel`)
แถบเทาไล่เงา ใช้ตอนโหลด ทำทรงตามเนื้อหาจริง

## 2. ฟอร์ม

### Field (`.field`)
label (ตัวหนา 14px) + input + `hint` (เทา) หรือ `error` (แดง ใต้ช่อง) · error ทำกรอบช่องเป็นแดง

### TextInput / Select / Textarea (`.in`)
สูง 46px · radius 14 · พื้น `--bg` · textarea สูง 120px ปรับได้
รองรับ `autocomplete` ที่ถูกต้อง (username, current-password, new-password, email)

### PasswordInput
ปุ่มตาแสดง/ซ่อนในช่อง · `strength` meter 4 แท่ง (อ่อนมาก → แข็งแรง) · hint ความยาวขั้นต่ำ

### Checkbox (`.check`) · Radio
สีเน้น `--orange` · ข้อความยาวได้หลายบรรทัด

### Toggle (`.toggle`)
46×28 · เปิด = `--go` · ต้องมี `aria-label` และ `aria-pressed`

### Segmented (`.seg`)
ตัวเลือกแบบปุ่มติดกัน (role=radiogroup) · ตัวที่เลือกพื้น `--ink` · บนจอแคบเลื่อนแนวนอน ห้ามตัดบรรทัด

### SearchBox (`.searchbox`)
pill + ไอคอนค้นหา · ใน header = ปุ่มไปหน้าค้นหา · ในหน้า = input ค้นสด

### Captcha
กล่อง “ฉันไม่ใช่บอท” แสดงเมื่อ: ฟอร์มติดต่อ, สมัคร, ล็อกอินผิด ≥3 ครั้ง

### CodeInput (รหัสจับคู่)
6 หลัก ตัวใหญ่ เว้นตัวอักษร `inputmode=numeric` · error “รหัสไม่ถูกต้องหรือหมดอายุ”

### ColorSwatches
8 สีสำเร็จรูป + ปุ่ม + เลือกสีเอง · เตือนเมื่อสีซ้ำกับหุ่นตัวอื่น

### FileDrop
กล่องเส้นประ “ลากไฟล์มาวาง หรือกดเลือกไฟล์” + ชนิด/ขนาดที่รับ

## 3. แสดงผล

### Card (`.card`)
radius 22 · พื้น `--panel` (โปร่ง + blur) · ขอบ `--line` · padding 20/22
`selected`: ขอบ 2px สีที่กำหนด (ส้ม หรือสีหุ่น)

### Notice (`.notice`)
`tone`: `warn` · `red` · `blue` · `go` · ไอคอน + ข้อความ (+ ปุ่ม) · ใช้แจ้งในเนื้อหา

### Banner (`.banner`)
แถบเต็มความกว้างบนสุด · `info` · `warn` · `red` (ทึบ ตัวขาว) · ปิดได้ · ใช้กับ ประกาศ, ปิดปรับปรุง, ROS หลุด, ตัวเชื่อมหลุด, ยังไม่ยืนยันอีเมล

### EmptyState
ไอคอนในกล่องมน 72px + หัวข้อ + คำอธิบายที่บอกขั้นต่อไป + ปุ่ม

### Gate
หน้าเต็มสำหรับ 403 / ต้องล็อกอิน / ต้องติดตั้งตัวเชื่อม / ถูกระงับ / 404 / 500 · ไอคอน 96px + หัวข้อ + คำอธิบาย + ปุ่ม 1–2 ปุ่ม

### Table (`table.t`)
หัวตาราง mono ตัวพิมพ์ใหญ่เล็ก · แถว hover · ห่อด้วย `.tscroll` ให้เลื่อนแนวนอนบนจอแคบ

### Pager
ใช้กับทุกรายการที่อาจเกิน 10
| ส่วน | พฤติกรรม |
|---|---|
| ≤10 รายการ | แสดงแค่ “ทั้งหมด N รายการ” |
| ขนาดหน้า | select 10 / 20 / 30 / 50 (ค่าเริ่มต้น 10) · เปลี่ยนแล้วกลับหน้า 1 |
| ช่วง | “21–40 จาก 48” |
| ปุ่มหน้า | ‹ 1 2 3 … 9 › · แสดงหน้าแรก หน้าสุดท้าย และ ±1 รอบหน้าปัจจุบัน · หน้าปัจจุบัน `aria-current="page"` |
| ตำแหน่ง | บนและล่างรายการ |
| หลังเปลี่ยนหน้า | เลื่อนขึ้นต้นรายการ |
| เปลี่ยนตัวกรอง/คำค้น | กลับหน้า 1 แต่จำขนาดหน้า |

ฝั่ง API: `?page=&page_size=` คืน `{ items, total }`

### Tabs
underline สีส้ม 3px · role=tablist/tab/aria-selected · ใช้ใน โปรไฟล์ รายละเอียดภารกิจ ตั้งค่าเว็บ

### StepList / Stepper
- `Stepper` (pill เรียงแถว): ขั้นเสร็จ ✓ เขียว · ขั้นปัจจุบัน ส้ม · ขั้นถัดไป เทา
- `StepCard` (หน้า setup): การ์ดใหญ่ เลขในกล่อง · ปัจจุบันกรอบส้ม · ยังไม่ถึงจาง

### ProgressSteps (ความคืบหน้ารันซิม)
แต่ละขั้น: วงกลม (เลข / ↻ / ✓) + ชื่อ + สถานะ (กำลังทำ / เสร็จ / ข้าม) · ขั้นที่ยังไม่ถึงจาง

### TerminalOutput
กล่องพื้นดำ ฟอนต์ mono 12px สูงสุด 180px เลื่อนได้ · บรรทัด error สีแดง · finished/ready สีเขียว · ซ่อนใน `<details>` (เปิดเองเมื่อผิดพลาด)

### Battery
แบตแนวนอน + ตัวเลข % · สี: <25 แดง · <45 เหลือง · อื่นๆ เขียว · แสดงตลอด ไม่ต้องกดขอ

### Toast
ล่างกลางจอ พื้น `--ink` · หายเองใน 2.6 วินาที · role=status · ใช้ยืนยันการกระทำ

## 4. ทับซ้อน

### Modal (`.modal`)
กว้างสูงสุด 520 · radius 26 · หัว + ปุ่มปิด + เนื้อหา + ปุ่มชิดขวา · คลิกพื้นหลังหรือ Esc = ปิด · `danger` = หัวข้อสีแดง
ใช้กับ: หยุดทุกตัว, จบภารกิจ, บันทึกภารกิจ (ล็อกอินแล้ว / ยังไม่ล็อกอิน), แก้ชื่อสีหุ่น, เพิ่มโลก, เลือกแผนที่อ้างอิง, ลบบัญชี, เชิญผู้ใช้, ลบบทเรียน, ลบภารกิจ, ประกาศ, เปิด/ปิดปรับปรุง, กู้คืน
**การกระทำอันตราย:** ต้องพิมพ์ยืนยัน (ชื่อผู้ใช้ / “กู้คืน”) ปุ่มยืนยันจึงกดได้

### Drawer (`.dr`)
แผงขวา กว้าง ≤460 · ใช้จัดการผู้ใช้ (มุมมอง: ข้อมูล / ระงับ / ยกเลิกระงับ / เปลี่ยนบทบาท / ลบ) ในแผงเดียว

### Menu (`.menu`)
dropdown เมนูผู้ใช้: ชื่อ + บทบาท + อีเมล · โปรไฟล์ · ประวัติ · คอนโซล · หลังบ้าน (เฉพาะผู้ดูแล) · ออกจากระบบ

### CookieBanner
ล่างจอ · “ปฏิเสธทั้งหมด” และ “ยอมรับทั้งหมด” ขนาดเท่ากัน · “ตั้งค่าเอง” → toggle รายหมวด (จำเป็น=ล็อกเปิด / จำการตั้งค่า / สถิติ) · ลิงก์นโยบาย

## 5. Layout

### SiteHeader (`.hdr`)
sticky · โลโก้ · เมนูหลัก (หน้าแรก บทเรียน รู้จักหุ่น เกี่ยวกับ) · ค้นหา · สลับธีม · เปิดคอนโซล · ล็อกอิน/สมัคร หรือ Avatar + Menu · ≤900px เหลือไอคอน + แฮมเบอร์เกอร์ (MobileDrawer)

### SiteFooter (`.ftr`)
4 คอลัมน์: เกี่ยวกับเว็บ + เวอร์ชัน · ใช้งาน · ติดต่อ · นโยบาย (รวม “ตั้งค่าคุกกี้”) · ≤800px เหลือ 2 คอลัมน์

### AuthShell
header เล็ก + การ์ดกลางจอ กว้าง 440

### ConsoleShell
header + banners + แถวบน (ป้าย “คอนโซลหุ่น” + AgentStatusChip) + เนื้อหา (ยืดเต็ม) + **ConsoleNav**

### ConsoleNav (`.cnav`)
**ล็อกติดขอบล่างเสมอ** แม้เนื้อหาสั้น (เนื้อหา flex:1 ดันลง + sticky bottom) · พื้นเบลอ + เงาบน
รายการ: ควบคุม · เชื่อมหุ่น · ประวัติ · หุ่นของทีม · หยุดทุกตัว (แดง ขวาสุด → Modal ยืนยัน)
≤700px: 5 ช่องกว้างเท่ากัน ไอคอนบน ชื่อล่าง

### AdminShell
sidebar 248px (โลโก้ + ป้ายบทบาท + กลุ่มเมนูที่กรองตามสิทธิ์ + ดูหน้าเว็บ + คอนโซล) + topbar (ชื่อหน้า คำอธิบาย ปุ่ม ธีม avatar) + เนื้อหา · ≤900px sidebar ซ่อน เปิดด้วยปุ่มเมนู

### ReadOnlyBadge
pill เทา “ดูอย่างเดียว” ใน topbar เมื่อดูได้แต่แก้ไม่ได้

## 6. เฉพาะโดเมน

### AgentStatusChip
pill ตามสถานะตัวเชื่อม · ok = จุดเขียวกะพริบ + “เครื่องนี้ · Ubuntu-22.04 · v0.3.1” · อื่นๆ = ไอคอน + ข้อความ · กด → หน้า setup

### AgentGate
Gate ที่ข้อความตามสถานะตัวเชื่อม + ปุ่ม “ติดตั้ง/ไปหน้าเชื่อมเครื่อง” + “อ่านบทเรียน”

### DoctorList
รายการตรวจเครื่อง: ไอคอน ✓/✕ + ชื่อ + รายละเอียด mono · ปุ่มตรวจอีกครั้ง · ขาดอะไร → ลิงก์บทเรียนที่เกี่ยว

### SimRunForm
จำนวนหุ่น (Segmented) · โลก (Select + เพิ่ม .sdf) · Toggle build · Toggle headless · แผนที่อ้างอิง · ขั้นสูง (details) · คำสั่งที่จะรัน (details) · ปุ่มรัน (loading)

### RobotPickCard
| prop | |
|---|---|
| `robot` | ชื่อ สี เลข สถานะ แบต โหมด |
| `selected` | ขอบ 2px สีหุ่น |
| `canControl` | เปิด/ปิด segmented โหมด |
| `onEdit` | ปุ่มดินสอ → Modal แก้ชื่อสี |
มีการ์ด “ทุกตัว” แยก (ไอคอนหุ่น) · แถวการ์ด = ตัวเลือกเดียวที่คุมทั้ง MazeMap และ LogFeed · ≤640px ปัดซ้าย–ขวา
แบตต่ำ <25% → Notice แดงในการ์ด

### MazeMap (SVG)
| prop | |
|---|---|
| `filter` | `all` หรือ index หุ่น |
| `view` | `trail` · `both` · `full` |
| `robots` | แสดงตำแหน่งหุ่น (วงกลมสี + เลข + วงกระเพื่อม) |
| `referenceMap` | ถ้าไม่มี ปิด view both/full |
องค์ประกอบ: ตารางพื้น · เส้นทาง (สีหุ่นตัวแรกที่ผ่าน, ปลายมน) · **ทางแยก = วงกลมขาวขอบดำ + ชื่อ J1..** · **ทางตัน = กากบาทแดง** · START · พื้นที่เป้าหมาย (แดงจาง) · ทางออกเส้นประ · เข็มทิศ
แผนที่อ้างอิง: `both` = เส้นเทากว้างจาง (opacity .28) ใต้เส้นหุ่น · `full` = เส้นเทาทึบ ไม่แสดงเส้นหุ่น

### MapViewSwitch
Segmented 3 ตัว: เส้นที่หุ่นลาก / แผนที่เต็ม + เส้นหุ่น / แผนที่เต็ม · ปิดสองตัวหลังถ้ายังไม่มีแผนที่อ้างอิง (tooltip “อัปโหลดแผนที่ก่อน”)

### MapLegend
