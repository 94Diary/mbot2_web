# mBot2 Maze Ops เฟส 2: หน้าเว็บสาธารณะ บทเรียน 3D และหลังบ้านที่เหลือ (design)

วันที่ 12 พ.ย. 2569 · ต่อจาก [เฟส 1](2026-11-12-maze-ops-phase1-design.md) · สถาปัตยกรรมเดิม (backend Node + SQLite บนเครื่องเดียว)

## เป้าหมาย

ทำให้เว็บมี **ทุกระบบตาม docs/pages-and-flows.md และ mockup** ยกเว้นส่วนที่ผู้ใช้สั่งเลื่อน:

- **ไม่ทำในเฟสนี้:** ระบบบัญชีแบบแน่นหนา (ล็อกบัญชี, CAPTCHA ตอนล็อกอิน, 2FA, ลืมรหัส, ยืนยันอีเมล, โปรไฟล์ 6 แท็บ, หน้าความปลอดภัย), หุ่นจริง (หน้าวางหุ่น, ค้นหาหุ่น), ตัวเชื่อมเครื่อง/จับคู่ 6 หลัก
- **บทเรียน:** ขึ้นโครง 13 บท (หัวข้อ สรุป และโครงหัวข้อย่อยในเนื้อหา) ให้ทีมเติมเนื้อหาเองในหลังบ้าน
- **3D:** หน้าแรกและหน้ารู้จักหุ่นใช้โมเดล `docs/model/mbot2.glb` หมุนได้จริง หน้ารู้จักหุ่นกดชิ้นส่วนแล้วชิ้นลอยออก (caster ลอยลงล่าง) ตามที่ mockup เขียนกำกับไว้

### ข้อมูลใหม่ (SQLite)
`lessons` · `lesson_progress` · `lesson_views` · `contact_messages` · `consent_records` · `backups`

### API ใหม่ (prefix `/api/v1`)
- สาธารณะ: `GET /lessons` · `GET /lessons/:slug` · `POST/DELETE /lessons/:id/progress` · `GET /search?q=` · `POST /contact` · `POST /consent` · `GET /site/status`
- หลังบ้าน: `/admin/lessons…` (+ `/restore`) · `/admin/messages…` · `/admin/system` · `/admin/machine` · `/admin/backups…`
- `GET /site` เพิ่ม description, noindex, contact_*

## การตัดสินใจ
- **markdown renderer เขียนเอง** แปลงเป็น React element ไม่ใช้ `dangerouslySetInnerHTML` → ไม่มี XSS แม้พิมพ์ HTML · รองรับ หัวข้อ ย่อหน้า ตัวหนา/เอียง/โค้ด ลิงก์ (http/https/ภายใน) รูป รายการ โค้ดบล็อก quote เส้นคั่น
- **3D ใช้ `three`** (dependency ใหม่ frontend 1 ตัว) โหลดแบบ lazy เฉพาะหน้าที่ใช้ · โมเดลคัดลอกไป `frontend/public/models/mbot2.glb`
- **หน้าเอกสาร** เขียนในโค้ด ไม่ทำ CMS เพิ่ม
- บทที่ 5 ใน mockup "ติดตั้งตัวเชื่อมเครื่อง" เปลี่ยนเป็น "เปิดเว็บคอนโซลบนเครื่อง" ให้ตรงสถาปัตยกรรมเครื่องเดียว

## ทดสอบ
backend `node:test`: สิทธิ์ทุก endpoint ใหม่ (401/403), ร่าง/members-only ไม่หลุดให้ผู้เยี่ยมชม, slug ซ้ำ, ถังขยะ/กู้คืน, progress, ค้นหาไม่คืนร่าง, ฟอร์มติดต่อ (validate, honeypot, rate limit), consent, สำรอง/ทดสอบกู้/กู้คืน (audit_log ไม่ถูกกู้) · frontend: markdown ไม่ render HTML/`javascript:` · build · เปิดหน้าจริงผ่าน dev server
