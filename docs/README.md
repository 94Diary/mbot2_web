# mBot2 Maze Ops — เอกสารส่งต่อให้ Dev

เว็บสำหรับโปรเจกต์ฝูงหุ่น mBot2 สำรวจเขาวงกต (ROS 2 Humble + Gazebo Fortress บน WSL)
เอกสารชุดนี้สรุปทุกอย่างที่ตกลงกันระหว่างออกแบบ เพื่อให้ Dev สร้างเว็บจริงต่อได้

> ต้นแบบที่กดได้จริง: `../mockup/mbot2-mockup.html` (ไฟล์เดียว เปิดในเบราว์เซอร์ได้เลย)
> มุมขวาล่างมีปุ่ม **จำลองสถานการณ์** ไว้สลับบทบาท อุปกรณ์ ธีม สถานะตัวเชื่อม ฯลฯ
> ทุกหน้าที่อ้างถึงในเอกสารนี้ เปิดดูได้จากแผงนั้น

## เว็บนี้คืออะไร (สรุปหนึ่งย่อหน้า)

เว็บสาธารณะที่ทำ 2 อย่าง: **สอน** (บทเรียนตั้งแต่ติดตั้งเครื่องจนหุ่นวิ่ง) และ **เป็นแผงควบคุม** ให้ใครก็ได้รันซิมหรือหุ่นจริง **บนเครื่องของตัวเอง** โดยกดปุ่มบนเว็บแทนการพิมพ์คำสั่งใน Terminal
โค้ดหุ่นและซิมรันบนเครื่องผู้ใช้เสมอ เว็บคุยกับเครื่องผ่านโปรแกรมเล็กที่ผู้ใช้ติดตั้งครั้งเดียว เรียกว่า **ตัวเชื่อมเครื่อง (agent)**
เซิร์ฟเวอร์ของเว็บเก็บแค่บัญชี เนื้อหา และประวัติภารกิจที่ผู้ใช้บันทึก

## คำศัพท์ที่ใช้ในเอกสาร

| คำ | ความหมาย |
|---|---|
| ตัวเชื่อมเครื่อง / agent | โปรแกรม Python ที่ผู้ใช้ติดตั้งใน WSL รับคำสั่งจากเว็บแล้วรันคำสั่ง ROS แทน |
| จับคู่ (pair) | ยืนยันว่าเครื่องนี้เป็นของผู้ใช้ ด้วยรหัส 6 หลักที่แสดงใน Ubuntu ได้ token กลับมา |
| ภารกิจ (mission) | การรันหนึ่งรอบ ตั้งแต่กดรันจนจบ มี log แผนที่ ผลลัพธ์ |
| โลกในซิม (world) | ไฟล์ `.sdf` ของ Gazebo = กำแพงที่หุ่นต้องสำรวจจริง |
| แผนที่อ้างอิง (reference map) | แผนที่ที่ใส่ไว้ดูบนเว็บเท่านั้น หุ่นไม่รู้แผนที่นี้ |
| เส้นที่หุ่นลาก (trail) | เส้นทางที่หุ่นเดินจริง สีตามหุ่นตัวแรกที่ผ่าน |
| ทางแยก / ทางตัน | จุดที่หุ่นมาร์กไว้ระหว่างสำรวจ แสดงเป็นจุดและกากบาทบนแผนที่ |
| โหมดสำรวจ / ตัดทาง | explore = เดินหาทางใหม่ · shortcut = วิ่งทางสั้นสุดไปเป้าหมายที่รู้แล้ว |
| เจ้าของระบบ (owner) | ผู้ดูแลที่มีสิทธิ์ทำเรื่องย้อนกลับยาก มีอย่างน้อย 1 คนเสมอ |
